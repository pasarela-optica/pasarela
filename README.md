# Pasarela óptica

El sitio compilado del canal óptico de Pasarela: pasar un fichero de una pantalla a una cámara con QR animados, en el
propio navegador, sin red y sin instalar nada. GitHub Pages lo sirve desde `docs/`.

Aquí solo está lo compilado. Las licencias de lo que lleva dentro están en `docs/LICENCIAS.txt`.
